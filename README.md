# 桌面整理

Windows 桌面图标分区整理工具。把桌面上散落的图标按类型分区摆好，并把位置固定下来，
之后不管怎么被拖乱，点一下就能回到原来的布局。

**它只改图标的坐标，不会移动、改名或删除任何文件。** 所有文件都还在原来的位置，
只是图标在桌面上的摆放变了。

## 特性

- **分区摆放**：按扩展名把图标归入软件、文件夹、文档、图片、视频、音频、压缩包、其他八个分区，同类聚在一起
- **位置固定**：把满意的布局记录成"固定布局"，之后一键归位；没固定过的图标自动在所属分区里补空位
- **可撤销**：每次整理前都会记下原位置，点"撤销上次整理"即可还原
- **自动处理冲突**：落位前自动关闭桌面的"自动排列图标"，否则设好的位置会被系统打乱
- **两种排布方式**：`固定布局归位`（保留你摆好的位置，只补新图标）与 `整体紧凑重排`（按分区重算所有位置）
- **命令行可用**：支持无界面调用，方便写进脚本或开机自启
- **界面自适应**：窗口高度按实际分区数量自动收紧，高 DPI 缩放下按真实比例渲染

## 环境要求

- Windows 10 / 11
- Python 3.10 及以上（开发环境为 3.13）
- PySide6（界面依赖，仅图形界面需要；命令行模式不需要）

```bash
pip install -r requirements.txt
```

## 快速开始

```bash
python main.py
```

会自动打开工具窗口。窗口顶部整条都可以按住拖动，右上角是最小化和关闭。

直接双击 `启动.bat` 也可以，它会自动检查并安装依赖，然后用无控制台窗口的方式启动。

### 界面上的按钮

| 操作 | 作用 |
| --- | --- |
| 一键整理 | 回到固定布局；没固定过的图标在所属分区里自动补位 |
| 固定当前位置 | 把桌面此刻的位置记为固定布局（自己拖完图标后点它） |
| 撤销上次整理 | 回到本次整理之前的位置 |
| 解除固定 | 清掉位置记录，图标保持不动，之后可自由摆放 |
| 开机自动启动 | 开启后每次开机静默归位一次 |

### 打包成单文件 exe

```bash
pip install pyinstaller
pyinstaller 桌面整理.spec
```

产物在 `dist\桌面整理.exe`，单个文件，免安装。打包后配置文件会写到
`%APPDATA%\桌面整理\config.json`，不会在桌面等目录生成文件。

## 命令行

| 参数 | 说明 |
| --- | --- |
| `--plan` | 预览两种整理效果，不做任何改动 |
| `--apply` | 一键整理（回到固定布局） |
| `--compact` | 重新排布（按分区整体紧凑重算） |
| `--fix` | 把桌面当前位置固定下来 |
| `--unfix` | 解除固定 |
| `--undo` | 撤销上次整理 |
| `--boot` | 开机自启用：静默归位一次后退出 |

不带任何参数则打开工具窗口。

## 工作原理

桌面图标由 `explorer.exe` 里的 `SysListView32` 控件承载。本工具通过向它发送
`LVM_GETITEMTEXTW` / `LVM_GETITEMPOSITION` / `LVM_SETITEMPOSITION` 等消息读写
图标的名称和坐标，跨进程读写时借用 `explorer` 进程内的远程内存。

所以它拿到的是**桌面真实显示的位置**，而不是靠猜；写的也只是坐标，不触碰文件系统。

摆放位置按"列优先"的网格计算（与资源管理器的排列方式一致），分区之间留空列做间隔。

## 目录结构

```
main.py         入口与命令行参数解析
ui.py           界面：设计令牌、样式表、无边框窗口
organizer.py    整理逻辑：配置读写与归位 / 固定 / 撤销 / 重排
classify.py     条目分类：扫描桌面目录，按扩展名归入分区
layout.py       布局计算：算出每个图标应该落在哪个坐标
desktop_api.py  Win32 桌面接口：定位 ListView、读写坐标、自动排列开关
startup.py      开机自启：读写 HKCU 的 Run 项
paths.py        路径定位：程序目录、数据目录、配置与图标位置
```

界面相关的颜色、圆角、字号都集中在 `ui.py` 的 `TOKENS` 与骨架尺寸常量里，改一处即可整体换肤。

## 注意事项

- **不要用管理员身份运行**。管理员进程读不到 `explorer.exe` 的内存，会直接报错。
  如果确实需要管理员权限，请改用不带界面权限的普通账户运行。
- 工具会关闭桌面的"自动排列图标"并写入注册表（`HKCU\...\Shell\Bags\1\Desktop`），
  否则设定好的位置会被系统重新打乱。想恢复就在桌面右键 → 查看 → 勾选"自动排列图标"。
- 多显示器、桌面文件夹被重定向（例如改到 D 盘）、隐藏扩展名等情况都已做过兼容处理，
  但不同系统版本仍可能有差异，建议先用 `python main.py --plan` 预览效果再执行。
- 配置文件中保存的是使用者自己桌面上图标的名字与坐标，属于个人数据，已被 `.gitignore` 排除，不会进仓库。

## 常见问题

**整理后位置没生效？**
检查桌面右键 → 查看 → "自动排列图标"是否又被勾上了。这个开关一旦打开，系统会接管所有图标位置。

**提示"无法读取桌面进程内存"？**
多半是以管理员身份运行的，换成普通权限启动即可。

**想换一套配色？**
改 `ui.py` 里的 `TOKENS` 字典：它集中了全部颜色，分区颜色在 `ZONE_COLORS`。
